# ski-mount

The published site: **https://iqis.github.io/ski-mount/**

- **Mount Hole Designer** — lay several bindings out on one ski, find shared inserts and tight
  spacing, print a 1:1 mounting template.
- **Shift Ruler** — a printable paper rule for moving a mount off the ski's recommended boot
  centre.
- **Hole patterns** — 113 binding patterns, each hole a coordinate in millimetres from a boot
  reference, with the template it was measured from.

Everything runs in the browser; nothing is uploaded. These pages are generated — the tools and the
extractors that produced the measurements live in a separate working repo.

Measurements were read from published maker and shop templates (Voilé, 22 Designs, Bishop,
Powderguide/Knut Pohl, SlideWright, EarnYourTurns, Binding Freedom); no one else's template files
are hosted here. Trademarks belong to their owners, and this site is not affiliated with any
binding maker.

**Planning numbers, not a jig — test-mount before drilling.**

Code is MIT licensed; the measurements are facts about published templates.
